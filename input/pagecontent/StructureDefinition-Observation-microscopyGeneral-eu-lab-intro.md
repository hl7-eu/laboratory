The open question of microscopy: the code asks what is there to see, the value
is the finding observed — a morphology, an organism, host cells, or *not
detected*. The staining is specimen processing (`Specimen.processing.procedure`),
the microscopy technique is the method, the amount of a finding is a
component, and several findings of one examination are grouped through
`hasMember`.

Where the code names the target of the examination, e.g. *Plasmodium sp
identified in Blood by Light microscopy*, the examination is a
[specific microscopy](StructureDefinition-Observation-microscopySpecific-eu-lab.html).

The conventions and the examples are described in the
[Microscopy](microbiology.html#microscopy) section of the [Microbiology](microbiology.html) page.
