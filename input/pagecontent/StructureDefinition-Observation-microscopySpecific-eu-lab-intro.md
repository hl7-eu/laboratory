The targeted question of microscopy: the code names the target, e.g. *Plasmodium
sp* or *Ova and parasites*, and the value says whether it was seen —
`Detected` or `Not detected`. For a code with the property `PrId` the value is
the organism where it is more specific than the target or other than the
target. For a code with the property `PrThr` an organism other than the target
is an observation of its own, grouped with this one through `hasMember`.

Staining, technique and amount are represented as in the
[general microscopy](StructureDefinition-Observation-microscopyGeneral-eu-lab.html).

The conventions and the examples are described in the
[Microscopy](microbiology.html#microscopy) section of the [Microbiology](microbiology.html) page.
