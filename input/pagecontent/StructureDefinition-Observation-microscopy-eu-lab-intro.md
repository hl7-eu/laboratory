The open half of microscopy: the code asks what is there to see, the value is
the finding observed. The staining is specimen processing
(`Specimen.processing.procedure`), the microscopy technique is the method, the
amount of a finding is a component, and several findings of one examination are
grouped through `hasMember`.

Where the object sought is already named in the test code — acid-fast bacilli,
leukocytes — and the answer is whether it was seen, the examination is a
[targeted detection](StructureDefinition-Observation-targetedDetection-eu-lab.html).

The conventions and the examples are described on the
[Microbiology](microbiology.html) page.
