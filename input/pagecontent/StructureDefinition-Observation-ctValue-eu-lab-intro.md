The Ct value of a qualitative real-time PCR, a decimal with the UCUM unit `1`.
The qualitative result read from it points at this observation through
`derivedFrom`. A Ct value is reported only where the manufacturer of the assay
provides for it; it is not comparable between assays and is not a load.

The conventions and the example are described in the
[Ct value](microbiology.html#ct-value) section of the [Microbiology](microbiology.html) page.
